Lokaler Analysebereich

Die Analyse ist auf diesem Gerät durch eine lokale Passphrase gesperrt. Beim ersten Start wird die Passphrase festgelegt.

Wichtige Einschränkung: Dies ist keine echte serverseitige Benutzeranmeldung. GitHub Pages und öffentlich bereitgestellte JSON-Dateien sind für technisch versierte Besucher zugänglich. Keine vertraulichen oder lizenzpflichtigen Daten hier veröffentlichen. Für echte Benutzerkonten ist ein Authentifizierungs-Backend erforderlich.
