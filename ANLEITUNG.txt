Coaches-Analyse 3.5.17

1. ZIP nach .github/workflows hochladen.
2. Entpacken und installieren:
   unzip -o .github/workflows/Coaches-Analyse-v3-5-17-Coach-Vorbereitung.zip
   python scripts/install_v3517.py
3. Pruefen:
   node --check docs/game-analysis-v3516.js
   node --check docs/coach-prep-v3517.js
   python tests/test_v3517.py
4. Auf GitHub veroeffentlichen:
   git add -A
   git commit -m "Coaches-Analyse 3.5.17 Coach Spielvorbereitung"
   git pull --rebase origin main
   git push origin main
5. Test in der Web-App: BBC Coburg gegen FC Bayern Basketball II; Coach-Reiter.
   Analyse des letzten Spiels muss zuerst geschlossen sein. Coach-Spielvorbereitung
   darunter zeigt Matchup-Prioritaeten und den Bezug zu Teamaufgaben des letzten Spiels.

Es werden keine lokal gespeicherten Daten, Spielanalysen oder Coach-Ziele geloescht.
